## 📖 1. 프로젝트 소개
**Tool-dino**는 모바일(Termux) 환경 및 데스크톱 파이썬 환경에서 간편하게 유틸리티 기능을 실행하고 확장할 수 있도록 설계된 가벼운 프레임워크입니다. 
확장성과 직관적인 스크립트 구성을 목표로 개발되었습니다.

---

## ✨ 2. 주요 기능
- **Termux 최적화**: 안드로이드 Termux 환경에서 원활한 스크립트 실행 지원
- **모듈형 구조**: 기능별로 유연하게 확장 가능한 파이썬 스크립트 구조
- **간편한 배포 및 연동**: Git을 통한 빠른 소스 동기화 및 관리

---
